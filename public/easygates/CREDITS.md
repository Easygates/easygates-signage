# Image Credits — public/easygates/

**AI-generated placeholders (≤ 300 KB)** created for the NovaSign
**EasyGates Direct · Trade Counter** demo campaign. They show generic gate
automation equipment and trade-counter scenes with no real brand logos,
packaging or recognisable people, and are intended to be replaced with your
own photography.

| File | Description |
|------|-------------|
| `sliding-gate-motor.jpg` | 230V sliding gate motor, rack rail, control panel, fobs and photocells on a dark bench |
| `gate-safety-test.jpg` | Engineer force-testing the closing edge of a driveway gate |
| `trade-counter.jpg` | Trade counter and warehouse dispatch area with a delivery van |
| `technical-support.jpg` | Technical support engineer with a control board and tablet |

## Usage

- Referenced as `/easygates/<file>.jpg` by the EasyGates Direct demo scenes and
  the template starters. Because they ship in `public/`, every scene that uses
  them is part of the offline failsafe pack.
- The EasyGates Direct slides also reuse the older bundled photos in
  `/trade/` (`gate-hero.jpg`, `gate-install.jpg`, `smart-panel.jpg`).

## Replacing them

Drop your own photos in with the same file names (JPG, 1600×900 or larger,
under 300 KB) — no code changes are needed. Keep real brand logos out unless
you own the rights to show them.
