# Image Credits — public/counter/

All images in this folder are **AI-generated product placeholders (1600×900, ≤ 200 KB)** created for the
NovaSign **RAPIDFIX · Trade Counter** demo campaign. They show generic tools with no real brand
logos, packaging or recognisable people, and are intended to be replaced with your own product
photography.

| File | Description | Source |
|------|-------------|--------|
| `drill-kit.jpg` | Cordless combi drill with two batteries, charger and hard case | AI-generated |
| `screws.jpg` | Clear tub of assorted wood screws (1,000-pack) | AI-generated |
| `socket-set.jpg` | Open socket & bit set in a moulded case | AI-generated |
| `work-gloves.jpg` | Pair of heavy-duty work gloves, grey/black with red cuffs | AI-generated |
| `site-torch.jpg` | Rechargeable LED site light on a folding stand | AI-generated |
| `tool-bag.jpg` | Heavy-duty black and red canvas tool bag | AI-generated |

## Usage

- Cut out on a white background, so they render well with `object-contain` on the white
  catalogue card (`bulk-buy`), the shelf labels (`shelf-edge`) and the optional photo strip
  (`click-collect`).
- The scenes reference them as `/counter/<file>.jpg`. Because they ship in `public/`, every
  scene that uses them is part of the offline failsafe pack.

## Replacing them

Drop your own photos in with the same file names (JPG, ideally 1600×900 or larger, under
300 KB) — no code changes are needed. Keep the product on a plain background for the trade-card
layouts; avoid real brand logos unless you own the rights to show them.
