# Image Credits — public/smartsecure/

**AI-generated placeholders (≤ 300 KB)** created for the NovaSign
**Smart & Secure · Showroom** demo campaign. They show generic smart home
rooms and hardware with no real brand logos, packaging or recognisable people,
and are intended to be replaced with your own photography.

| File | Description |
|------|-------------|
| `showroom.jpg` | Smart home showroom: demo living area, control panel and meeting pod |
| `cinema-room.jpg` | Home cinema demo room with a projection screen and LED cove lighting |
| `smart-lock.jpg` | Smart door lock with keypad and fingerprint reader on a modern front door |
| `smart-lighting.jpg` | Living room at dusk with colour-changing smart lighting |

## Usage

- Referenced as `/smartsecure/<file>.jpg` by the Smart & Secure demo scenes and
  the template starters. Because they ship in `public/`, every scene that uses
  them is part of the offline failsafe pack.

## Replacing them

Drop your own photos in with the same file names (JPG, 1600×900 or larger,
under 300 KB) — no code changes are needed. Keep real brand logos out unless
you own the rights to show them.
