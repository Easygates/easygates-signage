# public/events/

Artwork for one-off events, supplied by the business (not stock photography).

| File | What it is |
|------|------------|
| `open-day-2026-11-11-poster.jpg` | EasyGates Direct Trade Counter Open Day, Wednesday 11 November 2026. The 4:3 print poster, scaled to full height and centred on a 1920×1080 canvas with navy side bars, so a full-screen slide shows all of it with no cropping. |

Use a file here as the **Image URL** of a *Background Image / Video* slide
(`/events/<file>.jpg`). Keep event artwork at exactly 1920×1080 so it fills the
screen without being cropped; for a different shape, letterbox it first.

Files in `public/` are read when the server starts, so restart the server
after adding one.
